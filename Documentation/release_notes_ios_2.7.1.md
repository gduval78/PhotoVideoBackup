# App Store "What's New" — iOS 2.7.1 (build 55)

The App Store listing exists only in en-US (limit 4000 characters). Same content as the Android 2.7.1 notes (`android/store/release_notes_2.7.1.txt`).

## en-US
New backup templates: camera or SD card → NAS, and camera or SD card → folder + NAS. A folder in iCloud Drive is now detected from the folder you pick, and its protections apply automatically. Each backup card shows how the data travels: cable, Wi-Fi or mobile data. Run now shows a summary screen first. A backup can be set to run only when the phone is charging (for example from a power bank on a USB-C hub). The list of your backups now loads more reliably after an update.
