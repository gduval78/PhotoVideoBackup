One block per App Store Connect locale (limit 4000 characters each). Same text as the Android notes.

## en-US
New: Backups. Choose what to back up and where, then run it with one tap. Each backup has its own source, destinations (several folders and a NAS) and options. Your current setup is migrated automatically. Free: one backup; Pro: several backups, a second destination, NAS, SD/USB sources, LUT grading. Now in 12 languages: Japanese, Korean, Hindi and Arabic added.
